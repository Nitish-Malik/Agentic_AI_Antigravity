# 📄 AI Resume Screening & ATS Analyzer

## Overview

An AI-powered Resume Screening and ATS (Applicant Tracking System) Analyzer designed to help job seekers optimize their resumes and improve their chances of passing ATS screening.

The application evaluates resumes against job descriptions and provides actionable insights, including:

- ATS Match Score
- Missing Keywords
- Skills Gap Analysis
- Resume Improvement Suggestions
- Candidate Fit Assessment

---

## Problem Statement

Many companies use Applicant Tracking Systems (ATS) to filter resumes before they reach recruiters.

As a result, qualified candidates may be rejected because:

- Important keywords are missing
- Skills are not clearly highlighted
- Resume formatting is not ATS-friendly
- Experience does not align with the job requirements

This project helps bridge that gap using AI-powered analysis.

---

## Features

### ✅ Resume Analysis

Upload a resume and receive:

- Resume summary
- Skills extraction
- Experience overview
- ATS compatibility review

### ✅ Job Description Matching

Compare a resume against a target job description.

Outputs include:

- Match Percentage
- Relevant Skills Match
- Missing Requirements
- Improvement Areas

### ✅ Keyword Optimization

Identify:

- Missing technical skills
- Missing business skills
- Industry-specific keywords
- High-impact recruitment terms

### ✅ Personalized Recommendations

Get suggestions on:

- Resume improvements
- Skill additions
- Better wording
- Stronger achievement statements
