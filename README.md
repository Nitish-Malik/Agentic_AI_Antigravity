## What is Agentic AI?

Agentic AI refers to AI systems that can:

1. Understand objectives
2. Create execution plans
3. Use available tools
4. Make decisions
5. Adapt based on results
6. Complete tasks with minimal human intervention

Unlike traditional chatbots, agentic systems can perform multi-step workflows autonomously.
